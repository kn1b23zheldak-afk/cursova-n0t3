Вебзастосунок для збереження, упорядкування та пошуку особистих нотаток і цифрових матеріалів

> **Курсова робота** з розробки програмного забезпечення  
> **Тема:** Створення вебзастосунку для збереження, упорядкування та пошуку особистих нотаток і цифрових матеріалів.

---

## 📌 1. Опис та мета проєкту

Метою проєкту є створення сучасного, швидкого та адаптивного вебзастосунку, який забезпечує користувача єдиним зручним цифровим простором для організації:
- текстових нотаток (з підтримкою **Markdown**-розмітки);
- цифрових закладок та веб-посилань;
- прикріплених файлів та документів (PDF, зображення, архіви, офісні документи тощо);
- фрагментів вихідного коду з підсвічуванням синтаксису;
- інтерактивних чеклістів та списків завдань.

## 🏗️ 3. Архітектура та технологічний стек

Застосунок побудовано за клієнт-серверною архітектурою з використанням **RESTful API**:

- **Бекенд (Backend):** Python 3.11 + фреймворк **Flask** (обробка HTTP-запитів, валідація, завантаження файлів, маршрутизація API).
- **База даних (Database):** **SQLite3** (вбудована реляційна СУБД, відсутність потреби у сторонніх серверах баз даних). Підтримує цілісність зв'язків через Foreign Keys та каскадне видалення (`ON DELETE CASCADE`).
- **Фронтенд (Frontend):** Адаптивний UI на базі **Tailwind CSS**, набір іконок **FontAwesome 6**, клієнтський рушій розмітки **Marked.js** для рендерингу Markdown.
- **Сховище матеріалів:** Локальна директорія `uploads/` із санітизацією імен файлів (`secure_filename`) та обмеженням розміру до 32 МБ.

## 🌐 5. Специфікація REST API

| Метод | Ендпоінт | Опис |
| :--- | :--- | :--- |
| `GET` | `/api/notes` | Отримання списку нотаток з фільтрами (`q`, `category_id`, `tags`, `type`, `sort_by`, `order`) |
| `GET` | `/api/notes/<id>` | Отримання повної інформації про одну нотатку |
| `POST` | `/api/notes` | Створення нової нотатки (підтримує JSON або multipart/form-data для файлів) |
| `PUT` | `/api/notes/<id>` | Оновлення нотатки |
| `DELETE` | `/api/notes/<id>` | Видалення нотатки та її прикріпленого файлу з диску |
| `POST` | `/api/notes/<id>/pin` | Перемикання закріплення нотатки зверху списку |
| `POST` | `/api/notes/<id>/archive` | Переміщення в архів / відновлення |
| `GET` | `/api/categories` | Список усіх категорій із лічильниками нотаток |
| `POST` | `/api/categories` | Створення нової категорії |
| `DELETE` | `/api/categories/<id>` | Видалення категорії |
| `GET` | `/api/tags` | Отримання всіх тегів та кількості їх використань |
| `POST` | `/api/tags` | Створення нового тегу |
| `DELETE` | `/api/tags/<id>` | Видалення тегу |
| `GET` | `/api/stats` | Загальна статистика системи (кількість нотаток, файлів, типів) |
| `GET` | `/api/export` | Експорт повної бази даних нотаток у JSON-файл |

## 🚀 6. Інструкція із запуску проєкту

### Варіант А: Швидкий запуск (Windows)
1. Просто двічі клацніть файл **`run.bat`** у корені проєкту.
2. Скрипт автоматично встановить потрібні бібліотеки, запустить локальний веб-сервер та відкриє застосунок у вашому браузері.

### Варіант Б: Запуск через командний рядок (PowerShell / CMD / Bash)
1. Переконайтеся, що встановлено Python 3.8+:
   ```bash
   python --version
   ```
2. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустіть сервер:
   ```bash
   python app.py
   ```
4. Відкрийте браузер і перейдіть за адресою:
   **[http://127.0.0.1:5000](http://127.0.0.1:5000)**
